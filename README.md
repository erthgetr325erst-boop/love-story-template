# 💕 موقع رومانسي | Romantic Love & Apology Website Template

قالب موقع رومانسي تفاعلي مفتوح المصدر لتوثيق قصة حب، اعتذار رومانسي، أو الاحتفال بعيد ميلاد وذكرى سنوية. الموقع مصمم بنظام ملفات نظيف ومقسم بالكامل (Modular Architecture) ليسهل على أي شخص تعديله وتخصيصه في دقائق دون الحاجة لخبرة برمجية.

---

## 📁 هيكل المشروع | Project Structure

```text
├── index.html        # هيكل الصفحة وجميع نصوص الأقسام والتايملاين
├── config.js         # ✏️ الملف الرئيسي للتعديل (الأسماء، التواريخ، كلمة السر، والأغنية)
├── style.css         # جميع التنسيقات والألوان والتصميم
├── script.js         # محرك الأنيميشن، تساقط القلوب، والعدّادات التفاعلية
├── README.md         # دليل الاستخدام وطريقة النشر
├── LICENSE           # رخصة MIT مفتوحة المصدر
└── .gitignore        # ملف تجاهل الملفات المؤقتة
```

## ⚙️ كيف تعدل الموقع؟ | How to Customize

### 1️⃣ التعديل السريع (الأسماء، التواريخ، كلمة السر، والأغنية):
افتح ملف **`config.js`** فقط، وستجد كل الإعدادات مشروحة بوضوح:

```javascript
const CONFIG = {
    // 👤 [1] أسماء الأشخاص
    partnerName: "اسم الحبيبة",              // اسم شريكة حياتك (سيظهر في كل الموقع)
    yourName: "حبيبك للأبد",                  // اسمك أو لقبك (يظهر كتوقيع أسفل الرسالة)

    // 🔐 [2] كلمات المرور لشاشة القفل
    passwords: [
        "1234",
        "love",
        "01012024",
        "01/01/2024"
    ],
    passwordHint: "💡 التلميح: يوم ما اتعرفنا على بعض", // التلميح الذي يظهر تحت حقل الإدخال

    // ⏳ [3] تاريخ بداية العلاقة أو التعارف (لتشغيل عدّاد الحب)
    // ⚠️ تنبيه: الأشهر في البرمجة تبدأ من 0 (يناير = 0, فبراير = 1 ... سبتمبر = 8 ... ديسمبر = 11)
    relationshipStartDate: {
        year: 2024,    // سنة البداية
        month: 0,      // الشهر (يناير = 0)
        day: 1         // اليوم
    },
    startDateLabel: "من يوم [تاريخ التعارف] وإحنا مع بعض",

    // 🎂 [4] تاريخ ميلاد الحبيبة (لحساب العمر تلقائياً)
    birthDate: {
        year: 2004,    // سنة الميلاد
        month: 0,      // شهر الميلاد (يناير = 0)
        day: 1         // يوم الميلاد
    },
    birthdayLabel: "[1 يناير 2004]",

    // 🎵 [5] فيديو الأغنية من يوتيوب
    // ضع معرّف الفيديو (Video ID) فقط من رابط اليوتيوب
    // مثال: من الرابط https://youtu.be/KLJA-srM_yM المعرّف هو KLJA-srM_yM
    youtubeVideoId: "KLJA-srM_yM",
    songTitle: "حبيبي يا نور العين - عمرو دياب 🎶"
};
```

### 2️⃣ تعديل النصوص والتفاصيل في `index.html`:
ملف `index.html` الآن نظيف تماماً وخالٍ من الأكواد الطويلة، مقسم لأقسام واضحة:

| القسم في `index.html` | ماذا تعدل فيه؟ |
| :--- | :--- |
| **`[1] شاشة كلمة المرور`** | رسالة الدخول وتلميح الباسورد |
| **`[2] قسم الترحيب الرئيسي`** | العنوان الترحيبي والوصف |
| **`[3] قسم الاعتذار`** | رسالة الاعتذار الصادقة |
| **`[4] الأدوار (أنتِ كل حاجة)`** | بطاقات (حبيبتي، بنتي، صاحبتي، أختي) |
| **`[5] التايملاين (قصتنا الجميلة)`** | محطات الذكريات وتواريخها ونصوصها |
| **`[6] عيد الميلاد وحساب السن`** | نص بطاقة عيد الميلاد (السن يُحسب آلياً) |
| **`[7] عدّاد الحب الحي`** | عدّاد الثواني والأيام والشهور |
| **`[8] مشغل الأغنية`** | مشغل يوتيوب الأنيق |
| **`[9] رسالة من القلب`** | الرسالة الرومانسية وتوقيعك |
| **`[10] قسم الوعود`** | الوعود الصادقة لشريكة حياتك |

## 🚀 طريقة الرفع والنشر مجاناً | Deployment

### 1️⃣ عبر GitHub Pages (الأسهل والأسرع):
1. قم بإنشاء مستودع جديد (**New Repository**) على GitHub.
2. ارفع ملفات المشروع (`index.html`, `config.js`, `style.css`, `script.js`, `README.md`).
3. اذهب إلى إعدادات المستودع **Settings** > ثم من القائمة الجانبية اختر **Pages**.
4. تحت قسم **Build and deployment**، اختر الفرع `main` ثم اضغط **Save**.
5. سيظهر لك رابط الموقع جاهزاً خلال دقيقة لتشاركه مع شريكة حياتك!

### 2️⃣ عبر Cloudflare Pages:
1. سجل دخولك على [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. اختر **Workers & Pages** ثم اضغط **Create Application** > **Pages**.
3. قم بربط مستودع GitHub أو رفع المجلد مباشرة، واضغط **Deploy**.
